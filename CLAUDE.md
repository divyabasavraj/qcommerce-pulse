Design and milestones: `PLAN.md`.

## Project log (required)
`docs/PROJECT_LOG.md` is the record of all work on this project. In every session that changes anything:
- Add a dated entry at the bottom (`## YYYY-MM-DD: <short title>`), or extend today's entry if one exists,
  with **Work done** (every task, with file paths and concrete results/numbers), **Decisions** (with the reason),
  **Failures and fixes** (what broke, how it was caught, the fix), and **Next**.
- Update the **Status** table and **Open decisions** list at the top.
- Log failures and dead ends too, not just successes. This log is interview prep.
- Don't log the automatic daily CI collection runs; those go in `run_log.csv` in the `data` release.
